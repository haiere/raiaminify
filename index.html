Frequently asked

Questions, answered.

Everything you need to know before you drop your first file.

Is RaiaMinify free to use?
Yes. RaiaMinify is completely free with no account, no sign-up and no file limits. Optional donations help keep the project alive and ad-free.
Are my files uploaded to a server?
No. Every minification step runs in your browser using JavaScript. Your files never leave your device and are never transmitted anywhere.
Which file types are supported?
RaiaMinify supports JavaScript (.js, .mjs, .cjs, .jsx, .ts, .tsx), CSS (.css), HTML (.html, .htm) and JSON (.json). Unknown extensions fall back to a safe generic whitespace cleaner.
Will minifying break my code?
The minifiers are language-aware and protect strings, template literals, regular expressions and the contents of pre, textarea, script and style blocks. Always test the output before deploying to production.
What is the maximum file size?
There is no hard limit. Because processing happens locally, the practical limit is your device's available memory. Files of several megabytes are handled comfortably.
Can I use the minified output commercially?
Absolutely. You own your code. The minified output belongs entirely to you and can be used in any personal or commercial project.
